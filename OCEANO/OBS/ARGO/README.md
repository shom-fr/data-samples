# Profils Argo

Source : programme international [Argo](https://argo.ucsd.edu), fichiers de profils du
[GDAC](https://argo.ucsd.edu/data/data-from-gdacs/).
Les données Argo sont libres de diffusion : citer le programme Argo et le
[DOI des données](https://doi.org/10.17882/42182).

Ce fichier est utilisé par le [cours de python pour l'océanographie](https://gitlab.com/GitShom/STM/cours-python-oceano) du Shom.

| Fichier | Contenu |
|---------|---------|
| `6901027_prof.nc` | 208 profils de température et salinité du flotteur PROVOR 6901027 (centre de données Coriolis), de juillet 2012 à mars 2018, Atlantique Nord subpolaire, 0-2000 dbar, en mode différé |

Téléchargement depuis le GDAC :

```bash
wget https://data-argo.ifremer.fr/dac/coriolis/6901027/6901027_prof.nc
```
