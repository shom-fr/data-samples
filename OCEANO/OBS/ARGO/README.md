# Argo profiles

Source: international [Argo](https://argo.ucsd.edu) program, profile files of the
[GDAC](https://argo.ucsd.edu/data/data-from-gdacs/).
Argo data are free to use: cite the Argo program and the
[data DOI](https://doi.org/10.17882/42182).

| File | Content |
|------|---------|
| `6901027_prof.nc` | 208 temperature and salinity profiles of the PROVOR float 6901027 (Coriolis data center), from July 2012 to March 2018, subpolar North Atlantic, 0-2000 dbar, in delayed mode |

Download from the GDAC:

```bash
wget https://data-argo.ifremer.fr/dac/coriolis/6901027/6901027_prof.nc
```
