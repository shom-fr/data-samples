# Seasoar

Source: PROTEVS Med 2015 cruise.

| File | Content |
|------|---------|
| `radiale_lg6_CNV.small.cnv` | Seasoar transect, an undulating towed vehicle equipped with a Sea-Bird SBE 9 CTD, on 22 January 2015 off Corsica, in the `.cnv` format of SBE Data Processing |

The file is subsampled: one scan out of 4, that is 6 Hz instead of 24 Hz, with the `nvalues` and `interval` values of the header updated.
