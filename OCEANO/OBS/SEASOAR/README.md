# Seasoar

Ces fichiers sont utilisés par le [cours de python pour l'océanographie](https://gitlab.com/GitShom/STM/cours-python-oceano) du Shom.

Source : Campagne PROTEVS Med 2015.

| Fichier | Contenu |
|---------|---------|
| `radiale_lg6_CNV.small.cnv` | radiale du Seasoar, poisson remorqué ondulant équipé d'une CTD Sea-Bird SBE 9, le 22 janvier 2015 au large de la Corse, au format `.cnv` de SBE Data Processing |

Le fichier est sous-échantillonné : un scan sur 4, soit 6 Hz au lieu de 24 Hz, avec les valeurs `nvalues` et `interval` de l'en-tête mises à jour.
